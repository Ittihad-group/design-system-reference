## Add a new package

1. Create a sibling folder next to `EG/` (e.g. `BrandName/`)
2. Mirror the EG scaffold: `css/`, `js/`, `docs/`, `screens/`, `PRODUCT.md`, `DESIGN.md`
3. Link it in this README table
