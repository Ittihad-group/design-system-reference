### Logo anatomy

- Circular seal: stylized open door/window + **E** (red) + **G** (navy)
- Top arc AR: المصرية الألمانية
- Bottom arc: لصناعة منتجات · WPC & PVC
- Side stars separating arcs
- Wordmark: المصرية (red) + الألمانية (navy) + WPC & PVC / لصناعة منتجات

### Usage

| Context | Asset |
|---------|-------|
| Header (light) | `wordmark-color.png` or `mark.png` + text |
| Header / footer (dark) | `wordmark-white.png` |
| Favicon / app icon | `mark-350.png` / `favicon.png` |
| Splash / seal only | `mark.png` |

Clear space: ≥ height of the “EG” letters around the seal. Do not recolor the mark; use provided variants.
