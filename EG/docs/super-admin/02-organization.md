## SA-07 · بيانات الشركة والمصنع — P0 · [Approved] (القيم [Open] بنود 11 و13)

**Epic story:** كصاحب شركة أريد بياناتي الرسمية في مكان واحد، فتظهر صح على كل المستند ولا يخرج مستند بيانات تجريبية.

### الشاشات
| ID | الاسم | Route |
|----|-------|-------|
| SCR-CMP-01 | بيانات الشركة | `/super-admin/company` |
| SCR-CMP-02 | الختم والتوقيع (تبويب) | `/super-admin/company/seal` |
| SCR-CMP-03 | لوحة جاهزية المستندات (Banner/Panel) [New] | داخل SCR-CMP-01 |

**الحقول:** الاسم عربي · الاسم English · الرقم الضريبي · السجل التجاري · العنوان الرسمي · الخط الساخن · البريد · الموقع · موقع المصنع. **كلها Placeholder حتى استلام البيانات (بند 11 Open).**

### Use Cases
**UC-CMP-01 · تعديل بيانات رسمية** — Super Admin ← تعديل الحقل ← حفظ ← Step-up (حقول رسمية) ← `COMPANY.UPDATED` (قبل/بعد). التحقق: صيغة الرقم الضريبي والسجل التجاري **{Open: الصيغة}**.
**UC-CMP-02 · رفع الختم/التوقيع** — Dropzone (PNG شفاف، حد حجم **{Open}**) ← معاينة على قالب A4 ← حفظ ← `COMPANY.SEAL_UPLOADED`. (الصور الرسمية **[Open بند 13]**.)
**UC-CMP-03 · فحص جاهزية المستندات [New]** — النظام يحسب الحقول الناقصة/Placeholder ← بانر «ناقص: الرقم الضريبي، الختم…» ← يمنع تفعيل إصدار فواتير حقيقية قبل الاكتمال.
**UC-CMP-04 · لغة المستند لكل نوع** — عربي أو ثنائي اللغة (Approved كإعداد) ← يرتبط بـSA-13.

### AC
- **US-CMP-01** AC: أي حقل Placeholder يظهر بعلامة واضحة · لا يُصدَر مستند "حقيقي" وفيه Placeholder.
- **US-CMP-02** AC: لا ختم/توقيع تجريبي على مستند قابل للاستخدام (Approved).
- **US-CMP-03** AC: الشعار الرسمي لا يُرفع ولا يُغيَّر من هنا (Design Principle 2).
