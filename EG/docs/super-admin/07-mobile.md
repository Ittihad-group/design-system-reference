### Use Cases
**UC-MOB-01 · اعتماد/رفض من الموبايل** — إشعار Action ← فتح التطبيق على الشاشة ← التحقق من الجلسة والصلاحية والحالة الحالية ← عرض الإجراء ← قرار (+ Step-up بيومتري/كلمة مرور لو مالي) ← `APPROVAL.*`. **أونلاين فقط.**
**UC-MOB-02 · فك قفل/تعطيل/خروج إجباري** — أونلاين + Step-up + سبب ← `USER.*`.
**UC-MOB-03 · عرض النشاط والمؤشرات** — قراءة فقط؛ تُحمَّل مسبقًا للعرض دون اتصال (بلا إجراءات).
**UC-MOB-04 · جهاز مشترك** — خروج + مسح البيانات المحمّلة (بند 30 Approved).
