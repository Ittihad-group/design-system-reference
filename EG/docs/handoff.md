# Handoff

## For React (EG-System / EG-Website)

- Tokens → CSS variables or theme object
- Components map → `docs/components.md`
- Routes → `docs/ia-sitemap.md`

## For Flutter (EG-Mobile)

- ThemeData from tokens
- Screen list → `docs/screen-inventory.md`

## Assets

- Place logos in `assets/images/`
- Icons in `assets/icons/`
- Fonts in `assets/fonts/` (license notes here)

## Definition of done

- [ ] Tokens filled
- [ ] Live `design-system.html` shows all components
- [ ] Module docs filled
- [ ] Screen stubs reviewed with client
