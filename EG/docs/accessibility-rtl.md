# Accessibility & RTL

## Language

- Default: Arabic RTL
- Secondary: English LTR
- Switch owner: `js/i18n.js`

## RTL rules

- [ ] Logical CSS properties only
- [ ] Directional icons flip; logos/media do not
- [ ] Tables / charts direction notes

## WCAG checklist

- [ ] Contrast AA
- [ ] Focus visible
- [ ] Keyboard paths for ERP tables/forms
- [ ] Labels / errors associated
- [ ] `prefers-reduced-motion`
- [ ] Hit targets
